Galaxy A52s 5G (a52sxq) - ReSukiSU build notes
==============================================

Root solution
-------------
- ReSukiSU, built in (CONFIG_KSU=y), with SUSFS v2.3.0.
- Source: the KernelSU submodule, pointing at ReSukiSU (the repository
  has since been renamed to Baka-SU/BakaSU; the old URL redirects).
- drivers/kernelsu is a symlink to ../KernelSU/kernel, so the submodule
  must be initialized before building.

Versioning
----------
- ReSukiSU computes its version code from the submodule's commit count
  (30000 + count + 700) and its tag from git describe. The submodule must
  therefore have its full history and tags; a shallow clone reports a
  version code far below the manager's minimum and gets rejected:

    git submodule update --init
    git -C KernelSU fetch --unshallow --tags

- The manager also requires the kernel and manager UAPI versions
  (KERNEL_SU_UAPI_VERSION in KernelSU/uapi/supercall.h) to match exactly.

Building
--------
Built with Action-Kernel-Builder using the vendor/a52sxq_eur_open_defconfig
defconfig and the yupik.dtb device tree:

    ./build_a52sxq.sh -c -r

The rebuilt kernel modules are packed into the vendor_boot ramdisk so their
vermagic matches the new kernel.
